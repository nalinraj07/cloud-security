# Cloud Security Incident Response

## 1. Identify
- Review CloudTrail events
- Review GuardDuty findings
- Review Security Hub findings
- Identify affected resource and account

## 2. Contain
- Revoke compromised credentials
- Isolate affected workload/security group
- Block malicious network paths
- Preserve logs

## 3. Eradicate
- Remove malicious code
- Rotate credentials
- Patch vulnerable packages/images
- Rebuild from a trusted commit

## 4. Recover
- Redeploy clean image
- Validate IAM permissions
- Monitor logs and findings

## 5. Lessons learned
Document root cause, timeline, indicators, controls that failed, and preventive actions.
